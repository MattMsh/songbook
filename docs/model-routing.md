# Розподіл задач між моделями

Це робочий розподіл команди, а не універсальний рецепт OpenAI. Обирайте модель за складністю, вартістю та результатом перевірки. Людина або відповідальний агент перевіряє результат і безпеку змін.

| Модель | Що говорить OpenAI | Наше застосування |
| --- | --- | --- |
| [GPT-6 Astra](https://developers.openai.com/api/docs/models/gpt-6-astra) | Найпотужніша модель для складних задач, зокрема міркування та програмування. | Модель даних, архітектура, складні рішення та перевірка змін. |
| [GPT-6.1 Sol](https://developers.openai.com/api/docs/models/gpt-6.1-sol) | Результати для складних задач близькі до Astra за нижчої вартості; підтримує складне програмування. | Реалізація узгоджених задач і тестів. |
| [GPT-6.1 Terra](https://developers.openai.com/api/docs/models/gpt-6.1-terra) | Швидка модель для візуального аналізу, роботи з інтерфейсом і написання текстів. | Перевірка UX, локалізація та документація. |

[Посібник OpenAI з генерації коду](https://developers.openai.com/api/docs/guides/code-generation) рекомендує актуальні моделі загального призначення, зокрема Sol, для Codex. Для більшості задач генерації коду через API він пропонує починати з Astra. Наш розподіл не замінює ці рекомендації: Codex і прямий виклик API — різні способи роботи.

Не надсилайте моделям секрети або приватні дані користувачів без дозволу та належних гарантій захисту. Перевіряйте доступність моделей, тарифи й умови перед використанням за посиланнями вище.
