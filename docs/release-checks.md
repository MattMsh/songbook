### Перевірки перед збіркою

- `pnpm test`: 235 тестів пройдено; 500 російських перекладів перевірено.
- `pnpm typecheck` і `git diff --check`: помилок немає.
- Metro export для iOS та Android: `/tmp/songbook-grids-release-export`.
- API smoke: 73 основні перевірки та 31 перевірка планів пройдені.
- Тести охоплюють атрибути, сітки, бій, повтори, транспозицію, PDF, невідомі дані та збереження CRLF.
- Симулятор iPhone 18 Pro, iOS 27, Expo Go: створено й збережено сітку з акордами C/G та боєм.
- Локальний API зберігає повний ChordPro. Тестова пісня `d12c674f-78a7-4931-80c9-eaa9da242ab1` не потрапляє у production.
- Перевірено транспозицію C → Db, G → Ab без зміни бою.
- Темна тема й максимальний Dynamic Type: схема читається; акорди й бій прокручуються разом.
- Виправлено обрізання підпису інструментів музиканта при максимальному шрифті.
- Native `expo-print` створив односторінковий PDF. PDFKit підтвердив текст і стрілки; сторінку переглянуто.
- Після закриття системного вікна поширення тимчасовий PDF видалено.
- Fast Refresh спричинив `Access to closed resource`. Після холодного перезапуску перевірки збереження й транспозиції проходять без цієї помилки.
- Введення через команду емулятора не підтвердило текст. Назву введено екранними клавішами й перевірено в API.
- Фізичні пристрої, нативний Android, повний VoiceOver/TalkBack та доступ тестувальників не перевірено.

### Випуск

- Версію застосунку підвищено до `1.1.0`. Номер iOS-збірки визначає EAS.
- Потрібне оновлення Worker через зміну спільного парсера. Міграцій D1 і нових залежностей немає.
- EAS Build і Submit ще не запущені. Статуси буде записано після підтвердження сервісом.
- Межі підтримки: [сітки ChordPro](chordpro-grids.md). Метроном не виконує схеми й не підсвічує комірки.
