# Перевірка виправлень UX

Зміни інтегровано 28 жовтня 2026 року. Таблиця нижче описує повну регресійну перевірку; не всі сценарії перевірено вручну.

## Підтверджені результати

- `pnpm test`: 190 тестів; 407 російських перекладів. `pnpm typecheck` і `git diff --check` проходять.
- Локальні API smoke-тести: 73 основні та 31 перевірка планів.
- Окремий локальний HTTP-сценарій підтверджує видалення тестового акаунта, недійсність його сесії та безпечний повтор запиту.
- Expo Go, iPhone 18 Pro, iOS 27: нотатку збережено, повторно відкрито й показано біля куплету. Тестову нотатку прибрано.
- Перевірено попередження при виході з незбереженої нотатки та плану. Скасування виходу зберігає введені дані.
- Нативне меню заголовка відкриває інструменти. Нативний календар обирає дату; збережений план показує цю дату.
- Профіль перевірено з максимальним Dynamic Type: варіанти переносяться й масштабуються. Системний розмір повернуто до звичайного.
- Production API оновлено після резервного копіювання та міграції `0006_account_deletion_receipts.sql`.
- Нативні перевірки на фізичних пристроях, повний VoiceOver/TalkBack і реальний Apple-вхід із видаленням залишаються відкритими.
- Статус збірки та подання наведено в [перевірці випуску](release-checks.md).

Запишіть збірку, пристрій, версію ОС і результат кожного наступного сценарію. Використайте тестові акаунти та тестові дані.

## Реалізовані зміни

- Вихід попереджає про ненадіслані спільні зміни. Відкладені чернетки ізолюються за акаунтом.
- Повне оновлення спочатку завантажує каталог, а потім замінює локальні пісні. Діагностика показує стан і дає змогу повторити завантаження.
- Видалення потребує підтвердження `DELETE`. Воно завершує серверні сеанси та очищує особисті нотатки й аудіо цього акаунта на пристрої. Спільні пісні, плани, локальні альбоми й локальні зміни тексту залишаються. Після перерваного запиту або очищення дію можна повторити.
- Вхід запитує доступні способи в сервера та перевіряє доступність Apple на пристрої. Профіль показує доступні для озвучування варіанти й обраний стан.
- У плані є вибір дати. Незбережені зміни захищені під час виходу; приватні нотатки показуються біля секцій пісні. Інструменти доступні з заголовка пісні.

## Вхід Apple та видалення

Production зараз має лише вхід Apple; доставка magic link не налаштована. Не перевіряйте dev-авторизацію в production. Наявні старі акаунти не мають збережених Apple refresh/access tokens, тому автоматичне відкликання Apple для них недоступне. Видалення даних застосунку та відкликання дозволу Apple — окремі дії; користувач має отримати інструкцію для ручного відкликання. Див. [Apple TN3194](https://developer.apple.com/documentation/technotes/tn3194-handling-account-deletions-and-revoking-tokens-for-sign-in-with-apple).
